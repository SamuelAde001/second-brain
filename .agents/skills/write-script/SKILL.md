# Write a script

**Runs in the main session.** Act as the content agent: read `07-Agents/content/profile.md` and `memory.md` first, then the six non-negotiables at the bottom of [[brand-context]].

The method lives in two notes. This skill tells you which one to run and what to add. It doesn't copy them.

## 1. Which case is it?

- **A raw idea or a story, no script** → run [[script-process]] from Part 1. **Ask before writing anything.** Never invent a detail to fill a gap.
- **A draft he wrote** → run [[script-review-checklist]]. Sharpen and correct only; keep his wording, rhythm and structure.
- **A carousel** → keep his exact phrasing, condensed to fit the slides. Don't lift or paraphrase it.
- **He wants to see a draft now** → give it. Some intake questions are fine, but move with him when he's ready ([[script-process]] Part 5, rule 8).

## 2. What to use while writing

- **Structure:** Hook → Context → Conflict → Pivot → Resolution, plus Mantra only for a named series ([[brand-context]]). Other shapes, and the five named techniques (pronoun-as-plot, pacing-as-emotion, reframe pivot, bridge line, payoff-as-product close), are in [[storytelling-structures]]. Use one only when it fits the story.
- **Hooks:** 2–3 options from his own answers. Each states a real stake, pain or curiosity gap in the first line or two. Bold, never misleading. If he says *"that's not how I talk"*, rebuild toward his cadence at once.
- **Audience:** remote workers, creatives and video editors (Samuel, 2026-09-22). Keep it broad and borrowable unless the story is the point.
- **Visual direction** goes inline in braces, `{close-up on face}`. **B-roll never illustrates the line literally.** It shows ordinary work-from-home life, matched to the emotional beat.
- **Length:** 60s tight, 90s+ for calmer narrative.
- **Stories to draw on:** the 30-story bank in [[03-Areas/personal-brand/personal-brand-ideas|ideas]]. Note which one a script uses.

## 3. Before handing it over

Run the checklist in [[script-review-checklist]] on the final version, yours or his. Name real weak points. Flag any ambiguous line and ask; never guess what he meant.

## 4. Close

- If a story from the bank was used, change nothing in the bank; say which one in the log line.
- One line in `07-Agents/content/log.md`: date, the script's working title, which story, where it's saved (if he wants it saved, as a note under `03-Areas/personal-brand/scripts/<kebab-title>.md`, with frontmatter and a link back to [[03-Areas/personal-brand/personal-brand|Personal brand]]).
- Commit: `content: script <working title>`.
