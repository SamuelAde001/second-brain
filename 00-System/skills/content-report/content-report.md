# Content report

Samuel, 2026-09-22, on daily posting: *"Reported on Sundays, I may miss days when I am overloaded with Client work."* So this is a report, not an accountability check. **No escalation, no make-up rule, no lecture.** A missed day is a number.

**Runs in the main session.** Act as the content agent: read `07-Agents/content/profile.md` and `memory.md` first. The data lives in [[03-Areas/personal-brand/content-log|the content log]].

## 1. Ask, in one message

- **What went out this week?** Anything already in the log's Posts table is listed for him to confirm. A Reel, a TikTok or a carousel counts. The same video on both platforms is one post.
- **Followers now,** Instagram and TikTok. A screenshot is fine.
- **Views** on this week's posts, if he has them.

He inputs numbers *"sometimes"*. Whatever he doesn't give is recorded as missing. **Never guess a count or a view.**

## 2. Log it

Append to the content log: one Posts row per new post, one Views row per post he gave views for, one Followers row if he gave counts (source: `his words` or `screenshot`). Append only; never edit an old row.

## 3. Tell him, short

- **Days with a post: N of 7.** Just the number. If content dropped while client work ran, name P1 once ([[02-Me/patterns|patterns]]); no more.
- **Followers:** change since the last Followers row, per day.
- **Pace:** the goal is 5,000 by 2026-12-31. Say what's needed per day from here, next to what the last stretch did. The goal ladder's arithmetic uses Instagram; report TikTok beside it.
- **What performed:** best and worst post by views, if views were given. One line on what the best one had (series, format, topic), so the next idea starts there.
- Skip any line with no data, and say it's missing.

No praise. Numbers first.

## 4. Hand on

The weekly review runs next in the same session. It takes the content line from here (days posted, followers change) and doesn't recompute it.

## 5. Close

One line in `07-Agents/content/log.md`. Commit: `content: content report <YYYY-Www>`.
