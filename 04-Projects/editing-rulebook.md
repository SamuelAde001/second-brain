# Editing rulebook

Samuel, 2026-11-03: *"I want to build the ultimate editing rule book, this rule book will govern every edit from Routerise ... what would change between clients are the fonts, colors and for alex, square boxes instead of rounded corners"* and *"This rule book would be your number one rule, unless I tell you not to"*.

One rulebook for every Route Rise edit (Alex/Frontal, Gamma, any new client), built from every video so far, approved by Samuel section by section. Readable and editable by him in Obsidian, cheap for an agent to read: an index, one note per section, numbered rules, client overlays for what changes, reference images.
