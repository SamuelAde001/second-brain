# GEMINI.md

The rules for this Brain are in **AGENTS.md** at the Brain root. Read it first, in full, before doing anything here. It is the constitution: who Samuel is, the Brain map, how to find things, note conventions, operating rules, what must never be stored, and the agent and logging protocols.

`.gemini/settings.json` sets `context.fileName` to `["AGENTS.md", "GEMINI.md"]`, so AGENTS.md should load automatically. If it did not, open it manually.

This file is an adapter: it holds only what is specific to Gemini CLI. How any AI uses the Brain is in `00-System/portability.md`.

## Gemini's role: backup (when Claude's limits run out)

- Samuel, 2026-10-02: Gemini carries on Claude's work when Claude's limits run out, and Claude can hand Gemini jobs. The whole protocol: `00-System/relay.md`.
- **`/relay`** picks up what Claude Code was doing (a brief built from Claude's latest session and git). **`/handback`** logs where the work stands, commits and pushes when Samuel goes back to Claude.
- Writes like the primary, under AGENTS.md in full: append-only logs, no deleting, no rewriting history, the never-store list.
- Prefixes every commit message with `[gemini]`. Claude Code reviews every `[gemini]` commit at its next session.
- When Claude Code calls you through `00-System/scripts/ask_gemini.py`, you are a helper: read-only unless the task says you may edit, and you never commit.

## Running agents and skills from Gemini

- **Agents:** generated as native subagents in `.gemini/agents/` from `07-Agents/<name>/profile.md`. Each one is told it is the backup here. Without the subagent, read the profile and `memory.md` and act within it.
- **Skills:** generated in `.agents/skills/` from `00-System/skills/`. Or read `00-System/skills/<name>/<name>.md` directly.
- Never edit `.gemini/agents/` or `.agents/skills/` by hand — they are regenerated by `python 00-System/scripts/build_adapters.py`.
- **Connected here:** DaVinci Resolve and TickTick (`.gemini/settings.json`), Gmail, Calendar and Drive (the Google Workspace extension, if installed on this PC). The Brain's rules for each still hold: `00-System/relay.md` → What Gemini is connected to. A server that fails to connect: say so and stop at that step.
- **Tiers** are unmapped for Gemini; every agent runs on the session model.
- Ignore `.claude/` — generated copies for Claude Code.
