# GEMINI.md

The rules for this Brain are in **AGENTS.md** at the Brain root. Read it first, in full, before doing anything here. It is the constitution: who Samuel is, the Brain map, how to find things, note conventions, operating rules, what must never be stored, and the agent and logging protocols.

Antigravity CLI (`agy`) reads AGENTS.md and this file on its own. If AGENTS.md is not in your context, open it.

This file is an adapter: it holds only what is specific to Gemini, which here means **Antigravity CLI** (Gemini CLI's Google sign-in ended for personal and AI Pro accounts on 2026-06-18). How any AI uses the Brain is in `00-System/portability.md`.

## Gemini's role: backup (when Claude's limits run out)

- Samuel, 2026-10-02: Gemini carries on Claude's work when Claude's limits run out, and Claude can hand Gemini jobs. The whole protocol: `00-System/relay.md`.
- **`/pick-up`** picks up what Claude Code was doing (a brief built from Claude's latest session and git). **`/hand-back`** commits, logs where the work stands and pushes when Samuel goes back to Claude.
- Writes like the primary, under AGENTS.md in full: append-only logs, no deleting, no rewriting history, the never-store list.
- Prefixes every commit message with `[gemini]`. Claude Code reviews every `[gemini]` commit at its next session.
- When Claude Code calls you headless through `00-System/scripts/ask_gemini.py`, you are a read-only helper and never commit.

## Agents, skills, connections

- **Agents:** read `07-Agents/<name>/profile.md` and `memory.md` and act within them. Every reply opens with the agent's name (AGENTS.md §7).
- **Skills:** generated in `.agents/skills/` from `00-System/skills/`, so they run as `/<name>`. Never edit `.agents/skills/` by hand; it is regenerated by `python 00-System/scripts/build_adapters.py`.
- **Connected:** DaVinci Resolve and TickTick, in `.agents/mcp_config.json`. Gmail, Calendar and Drive are not connected yet. The rules for each: `00-System/relay.md` → What Gemini is connected to. A step that needs a missing or failing connection: say so and stop at that step.
- Ignore `.claude/` (Claude Code's generated copies) and `.gemini/` (left from Gemini CLI).
