# GEMINI.md

The rules for this Brain are in **AGENTS.md** at the Brain root. Read it first, in full, before doing anything here. It is the constitution: who Samuel is, the Brain map, how to find things, note conventions, operating rules, what must never be stored, and the agent and logging protocols.

Antigravity (the desktop app and the CLI, `agy`) reads AGENTS.md and this file on its own. If AGENTS.md is not in your context, open it.

This file is an adapter: it holds only what is specific to Gemini in Antigravity (Gemini CLI's Google sign-in ended for personal and AI Pro accounts on 2026-06-18). How any AI uses the Brain is in `00-System/portability.md`.

## Gemini's role: equal primary

- Samuel, 2026-10-02: *"you both should be on the same level, and not Gemini being second in place"*. Gemini and Claude Code are **equal primaries**: full access under AGENTS.md, the same agents, skills and guard rails. He uses whichever he wants, and either picks up the other's work. Protocol: `00-System/relay.md`.
- **Same rules, in full:** append-only logs, no deleting without his yes, no rewriting history, the never-store list, the agent name on every reply (AGENTS.md §7).
- **Commits** end with the trailer `Co-Authored-By: Gemini (Antigravity) <noreply@google.com>`, the way Claude's end with its own. Push after each, per AGENTS.md §12.
- **Session start** runs itself: `.agents/hooks.json` syncs GitHub on your first turn and names any commits Claude made since your last. Read them and the newest relay-log entry before carrying on. If the note didn't arrive, run `python 00-System/scripts/session_start_sync.py --for gemini`.
- **Guard rails** (`.agents/hooks.json` → `00-System/scripts/agy_guard.py`, the same lists as Claude's `.claude/settings.json`): reads of secrets are blocked; deletes, system changes, installs and history rewrites wait for Samuel's yes. Never work around a block; tell him.
- **`/pick-up`** carries on what Claude was doing. **`/hand-back`** commits, logs where the work stands and pushes when Samuel moves to Claude.
- **Work out loud.** Before the first tool call, say what you understood, what "done" means and your steps. After each step, one plain line on what you did and found. Ask before changing Resolve, TickTick or client files. Full rule: `00-System/relay.md` → Working where Samuel can follow it.
- **Model:** the strong tier, set in Antigravity's model menu (`00-System/portability.md` → tiers). Samuel picks it.
- When Claude Code calls you headless through `00-System/scripts/ask_gemini.py`, that one call is read-only and never commits.

- **Agents:** read `07-Agents/<name>/profile.md` and `memory.md` and act within them. Every reply opens with the agent's name (AGENTS.md §7).
- **Skills:** generated in `.agents/skills/` from `00-System/skills/`, so they run as `/<name>`. Never edit `.agents/skills/` by hand; it is regenerated by `python 00-System/scripts/build_adapters.py`.

- **Outside the Brain:** only the folders AGENTS.md §10 grants, for the agent it names.
- Ignore `.claude/` (Claude Code's generated copies) and `.gemini/` (left from Gemini CLI).
