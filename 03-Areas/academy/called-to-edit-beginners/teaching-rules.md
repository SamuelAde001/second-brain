# Teaching rules — Called to Edit: Beginner Course

Applies to every lesson in [[_index]]. Quoted and reproduced in full from the source's "The positioning this outline is built on" section.

## The core positioning

This is a course about **editing**, not about CapCut. CapCut is the demonstration vehicle — the tool the screen recording happens in. What a student walks away with is craft: how to cut, how to pace, how to build a look, how to use sound. That transfers to Premiere, Resolve, Final Cut, or whatever they move to in three years.

That distinction changes how every lesson is taught. It's not "here's the button." It's **"here's the principle, and here's what it looks like executed."**

## The lesson spine — used on every single lesson

The source calls this "the anti-rambling structure." Every lesson follows the same five beats:

| Beat | Time | Job |
|---|---|---|
| **1. Open** | 30–60 sec | State the claim. One sentence on why this matters. No preamble, no "hey guys." |
| **2. Principle** | 2–4 min | The transferable craft. Software-agnostic. This is the part that survives when they leave CapCut. |
| **3. Demo** | 5–10 min | Execute it on screen. Narrate the *decision*, not the click. |
| **4. The Trap** | 1–2 min | The mistake beginners make here, and what it looks like to a viewer. |
| **5. Drill** | 30–60 sec | One specific task with a defined output. Then get off camera. |

**Scoping test:** "If you can't state the Open in one sentence, the lesson isn't scoped tightly enough yet."

## Two rules to hold to while recording

1. **Say the principle before you touch the mouse.** "Once you start clicking, you'll drift into narrating the interface."
2. **Name the general concept alongside every CapCut-specific term, once.** Example given verbatim: *"This is the overlay track — every editor calls this a video layer or a track above."* The source calls this single habit "what makes the course transferable rather than disposable."

## Shot types

Three shot types are used across the course, defined in the source as:
- **Presentation** — you on camera or over slides, no software.
- **Screen Record** — software demo.
- **Live Edit** — unscripted full-project session.

Which shot type each lesson uses is recorded in that lesson's entry in the module notes ([[module-00-the-editors-mindset]] through [[module-07-finishing-publishing]]).
