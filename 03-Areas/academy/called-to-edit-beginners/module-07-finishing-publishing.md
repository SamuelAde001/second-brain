# Module 07 — Finishing & Publishing

*Two lessons and the capstone.* The last module of the course.

Every lesson runs the standard five-beat spine — Open → Principle → Demo → Trap → Drill. See [[teaching-rules]].

---

## 30. Export and Delivery

**Shot type:** Screen Record

**Open** — Export is where people quietly destroy work they spent hours on.

**Principle**
- **Resolution, frame rate, bitrate** — what each actually controls, and which matters most for upload quality.
- Why **bitrate** is the setting nobody touches and the one that shows.
- Frame-rate consistency: matching the export to the footage, and why mismatches stutter.
- **Aspect ratios and reframing** — delivering the same edit to 9:16, 1:1 and 16:9 without recomposing from scratch.
- Platform safe zones for Instagram, TikTok and Shorts.
- What compression on upload does to the file, and how to give the platform the best starting point.
- Watermarks, and how to deliver clean.
- The final check: **watch the exported file, not the timeline preview.**

**Demo**
- Export the same edit at a low and a high bitrate, compare on screen.
- Reframe a 9:16 edit to 16:9 live.
- Overlay platform safe zones on the final frame.
- Open the exported file and watch it back.

**The Trap**
- Exporting at defaults without ever checking what the defaults are.
- Never opening the exported file before uploading it.

**Drill**
- Export the edit, open the file, watch it end to end.
- Then export the same edit for a second aspect ratio.

## 31. The Final Review Pass

**Shot type:** Presentation

**Open** — The difference between a good editor and a fast one is what they do in the last ten minutes.

**Principle**
- The core problem: you have watched it 40 times and you can no longer see it.
- **Creating distance** — walk away, then watch it once as a viewer.
- **The mute test:** does it still hold with no sound? Exposes weak visuals and lazy pacing.
- **The 2× test:** exposes dead sections you have gone blind to.
- **The phone test:** watch it where it will actually be watched — at arm's length, in a normal room.
- The first-two-seconds check, once more, in isolation.
- **The "cut one more thing" rule** — there is always one section that can go.
- Knowing when it is done: the difference between finished and fiddling.
- Building this into a **checklist you run every single time**.

**Demo**
- Run the full review pass on a finished video, live.
- Find at least one real problem and fix it on camera.
- Show the checklist as a reusable list.

**The Trap**
- Posting the moment you finish, while still too close to it.
- Endless tweaking on something that was done an hour ago.

**Drill**
- Run all four tests on the edit before posting.
- Cut one more thing.

## 🔴 Live Edit 05 / Capstone — Full Build, Start to Finish

**Shot type:** Live Edit

**Format:** fresh footage, nothing prepared, the entire pipeline in real time. **The longest session in the course, and "the reason people finish it."**

**What to hit:**
- Watch and plan on camera — Module 00 applied, not skipped because it is the last lesson.
- Build the cut first and play it before adding anything.
- Layer in order: **text → visuals → colour → audio.**
- Narrate the principle behind every decision, calling back to the module it came from.
- Say out loud at least three things you are choosing **not** to do.
