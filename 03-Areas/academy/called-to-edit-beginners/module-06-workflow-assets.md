## 28. Sourcing Your Assets
**Shot type:** Presentation

**1. Open**
- The library you build over two years is worth more than any effect you'll ever learn

**2. Principle**
- Where good stock actually comes from, free and paid, and how to judge quality fast
- **Licensing that matters for posting:** what you can use commercially, what gets you claimed, what gets a video muted
- Music and SFX sourcing, and why the free library everyone uses makes everyone sound the same
- Avoiding stock that instantly reads generic — the shots everyone has seen a thousand times
- Shooting your own B-roll bank: 10 minutes of filming that pays off for a year
- What belongs in a personal asset library: footage, SFX, overlays, graphics, presets, fonts
- Naming and folder structure that still makes sense in six months
- Backing it up, because losing it is losing years

**3. Demo**
- Walk through your own asset library structure on screen
- Show the difference between a generic stock shot and a specific one in the same edit
- Demonstrate a naming convention that actually survives

**4. The Trap**
- Downloading assets into whatever folder is open, then never finding them again
- Building an edit around stock that has no relationship to your actual content

**5. Drill**
- Build the folder structure today, before you have anything to put in it
- Shoot 10 shots of your own environment and file them

## 29. Templates and Repeatable Workflow
**Shot type:** Screen Record

**1. Open**
- Speed doesn't come from editing faster. It comes from not starting from zero

**2. Principle**
- Why a repeatable format beats a blank timeline: consistency, speed, and less decision fatigue
- What belongs in a template: intro, caption style, color preset, lower thirds, outro, sequence settings
- Building a series template so every episode inherits the same identity **[CHECK: template / project duplication workflow on CapCut PC]**
- Reusable elements as a system rather than a folder of one-offs
- A repeatable edit order — the same pass sequence every time so you never wonder what's next
- Project organization: naming, versioning, and knowing which file is current
- Backing up projects and footage
- **The realistic target:** how workflow turns a three-hour edit into a 45-minute one without cutting quality

**3. Demo**
- Build a template from an existing finished project
- Start a new video from that template and show how much is already done
- Walk your own edit order pass by pass
- Show a versioning and naming convention

**4. The Trap**
- Templating so early that every video looks identical and nothing evolves
- No backup, one drive, no versions

**5. Drill**
- Turn your best edit into a template
- Start your next video from it and time yourself
