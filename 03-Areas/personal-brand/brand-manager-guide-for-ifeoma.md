# Brand manager guide for Ifeoma

For Ifeoma (Ivisuals), creative director. Samuel, 2026-10-26: you *"can ask brand manager any question concerning the brand and ... script with the brand manager"*.

## Open a session

1. On your laptop, sign in to Claude with Samuel's account and open **Code** (claude.ai/code, or the Code tab in the Claude app).
2. Pick the repository **SamuelAde001/second-brain** and start a new session.
3. Start with *"I'm Ifeoma"* or *"Ivisuals here"*, then your question. The reply starts with **[Brand manager]**.
4. Start your own session. Don't type into a session you didn't start: those are Samuel's, often mid-job on client work.

## What to ask it

- **Brand questions:** Samuel's voice and non-negotiables, his audience, what has performed, the Called to Edit brand guide (colours, fonts, logo use), past content plans.
- **Write a script together:** *"Let's script a Reel about …"*. It asks questions first, drafts 2-3 hooks, writes the script with visual notes, then checks it against Samuel's review checklist.
- **Review a draft or a hook:** paste it in and ask.
- **Ideas:** from Samuel's story bank, his teachings archive and what already went out.

## How it works

- **Samuel's stories come from Samuel.** It never invents a story detail or a number. If it doesn't know, it writes the question into the script for Samuel.
- **Scripts are saved in the Brain**, marked *with Ifeoma*. Samuel approves every script before he records it.
- **Brand only.** For money, Samuel's personal notes, client work or anything else, ask Samuel.
- **It never posts.** Posting is done by hand.
- **Your sessions share Samuel's usage limits.** Use one session per job, and finish it when the job's done.
