# Teaching formats for talking-head shorts

Samuel, 2026-10-28: *"I have the normal format for storytelling, but no format yet for my teachings shorts, I need a format that would always keep them engaged, very valuable and any teaching can fit in it."* Researched on Instagram and the web the same day.

**His decision, 2026-10-28:** *"for general format of script I can always use the spline you shared"* · *"save this all so I can tell you to give me a script on a certain topic, and based on what makes sense, you can use any of them to script it out for me"*. So the spine is the standard script shape for every teaching short, and the Brand manager picks the format per topic. He films seated in his chair. How the skill runs it: [[write-script]] → "A teaching".

The beat-level templates (Myth, Step-by-Step, Common Mistake, Authority) already sit in [[storytelling-structures]]. This note sits above them: one spine every teaching fits, a short set of named formats, and the visual layouts to rotate.

## What the research says

- **A format has two halves: what you say and how it looks.** Kallaway (@kallawaymarketing) plans a month by crossing a few topics with a few formats, then swapping the visual layout to double the output ("5 topics, 3 formats, 2 visual layouts"; later "6 topics, 5 formats"). His advice: start with easy formats (breakdowns, rankings) plus one ambitious one (scenarios, case studies).
- **The formats coaches and educators keep repeating in 2026:** myth bust, listicle, ranking, A vs B, green screen take, reaction, split screen, skit, screen share, yap, straight talking head (@kienobifilms, @approvedbybrooks, @drmattshiver).
- **A vs B is "crushing right now"** (Kallaway, Best Viral Formats ep. 4): beginner vs expert, bad vs good, before vs after. Two rules: compare the thing your viewer cares about most, and get to the contrast fast.
- **Pick one format, post it five times, let the numbers decide** (@kienobifilms).
- **Retention mechanics** (web guides, directional only): hook in the first second with text on screen, a new visual every 2–3 seconds, keep teaching Reels about 30–60 s, open a new question before closing the last one, end on a line that loops back to the start.

## The spine: any teaching fits this

Five beats. Every format below is this spine dressed differently.

1. **Hook (0–2 s).** The belief, the cost or the result, said and on screen at once. No "hey guys".
2. **Why me (one line).** Proof from his own path or his client work. Never a made-up number.
3. **The meat, countable.** Steps, mistakes, sides or ranks, with the number on screen. Tease the strongest point early ("number 3 is the one nobody does") so they stay.
4. **One real example.** His story, a screenshot, a DM, his timeline. This is what makes it his and not generic advice.
5. **Takeaway + CTA.** One sentence that loops back to the hook, then one action (follow, or comment a word for the Community).

## The six formats

| # | Format | Shape | Best teachings for it | Layout |
|---|---|---|---|---|
| 1 | **Myth bust** | Myth on screen → why people believe it → why it's wrong → what to do instead → CTA | Pricing, learning the skill, niche, tools | Green screen with the tweet or post that says the myth behind him |
| 2 | **The breakdown** | "The N steps I'd use to…" → each step in 1–2 lines with a counter on screen → recap | Finding clients, outreach, portfolio, packaging | Talking head with each step popping up as text |
| 3 | **A vs B** | "Beginner editor vs paid editor" → the same moment done both ways, back and forth → the one thing that separates them | Outreach (bad DM vs good DM), pricing, portfolio, client calls | Split screen or clone (two outfits, two positions), or labels on screen |
| 4 | **Ranking** | "Ranking N ways to … from worst to best" → each one gets a quick verdict → #1 last | Ways to find clients, tools, platforms, niches | Tier list or numbered column beside him |
| 5 | **Teardown** | Real example on screen (a DM, a portfolio, a pricing post) → what's wrong → the fixed version | Outreach, portfolio, personal brand | Green screen or screen share; blur names unless he has permission |
| 6 | **Answer a question** | A comment or Community question on screen → straight answer → his example | Anything from the Q&A ([[05-Knowledge/teachings/teachings-12-webinar-qa\|webinar Q&A]]) | Comment sticker over talking head |

**Stretch format:** the **scenario skit**, him playing the client and the editor. Highest effort, highest payoff, and it fits his own lesson from 2026-10-20: show the problem in a scene rather than state it.

## Filming seated in the chair

His default (2026-10-28). Every format works seated; the edit carries the variety.

| Format | What the edit adds |
|---|---|
| Myth bust | The myth as text, or as a screenshot above or beside him |
| The breakdown | A step counter and text for each step, a punch-in on each new step |
| Ranking | A list or tier graphic that fills in as he goes |
| Answer a question | The comment sticker at the top |
| Teardown | The DM or portfolio over the top half, him on the bottom half. An overlay, no real green screen needed |
| A vs B | Two takes from the same chair (lean or angle differently, or change top), cut back and forth or split screen. Simplest: one take with "BEGINNER" / "PAID EDITOR" labels flipping on screen |

Only the scenario skit really wants a second spot. The risk of the chair is sameness, so every script carries punch-ins, text and B-roll cutaways in its visual direction.

## Visual layouts to rotate

The same teaching can go out twice in two layouts.

1. **Straight to camera** at the navy marble wall, with a punch-in on every new point.
2. **Green screen**: the post, stat, DM or screenshot behind him.
3. **Split screen / clone**: for A vs B.
4. **Text-led**: the steps or ranks build up on screen while he talks.
5. **Voiceover on B-roll**: from the [[b-roll-archive|B-roll archive]] on days he can't film.

## How to start (the Brand manager's suggestion, not decided)

- Start with **Myth bust, The breakdown and A vs B.** All three fit the spine, need no set, and between them cover every teaching topic.
- Make five of one format before judging it. Log the format name with each post in the [[content-log|content log]] so the Sunday [[content-report]] can compare formats.
- Pick the teaching first from the [[05-Knowledge/teachings/teachings-archive|Teachings archive]], then the format that fits it. Never invent a teaching to fill a format.
