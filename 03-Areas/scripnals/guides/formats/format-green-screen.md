HOW THE SCRIPT CHANGES
- VISUAL says what is behind the user at each point: the post, the headline, the screenshot, the chart.
- Start with the thing being reacted to, so the viewer knows at once what this is about.
- The user's take is the content. The background only sets it up.
- Add something real: an opinion, a correction, a lesson. Reposting others' content without adding value gets pushed down.
AVOID
Reading the whole background out loud. Using someone else's full video.
