HOW THE SCRIPT CHANGES
- It is all spoken, so it must sound like talking, not reading. Short lines the user can say in one breath.
- First frame: the user already mid-sentence or mid-action, face close, with on-screen text that says the hook in 3 to 7 words.
- VISUAL lines: cut-ins, a change of angle or distance, on-screen text for key words, B-roll or a screen grab when they mention something the viewer should see. Plan a visual change every few lines so the picture never sits still for long.
- For unscripted talkers, keep the script as beats they can glance at.
AVOID
Long paragraphs to memorise. Opening on a wide, static shot.
