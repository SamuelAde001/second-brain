HOW THE SCRIPT CHANGES
- Write it as short dialogue lines, each starting with the character's name, like "CLIENT:" or "ME:".
- VISUAL lines say who is on screen, costume or position changes, and any props.
- Get into the scene in the first second. No setup line explaining the skit.
- Keep the punch for the last line or last reaction.
AVOID
More than 2 or 3 characters. Long speeches. Explaining the joke after it lands.
