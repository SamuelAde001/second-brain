WHAT IT IS
A numbered set: tips, mistakes, tools, signs, lessons. The number is the promise and the viewer counts along.

WHEN IT WORKS
Easy saves and sends. Good when the user has several small points on one topic, each useful alone.

DEFAULT BEATS
HOOK: the number, the topic and why it matters to the viewer.
BODY: Item 1 → Item 2 → Item 3 (→ 4, 5). Each item: its name in one short line, then one or two lines on why or how.
CTA: a save or a follow fits best. A real question also works: "which one do you do?"

STRUCTURES TO CHOOSE FROM
- Tips: N ways to get a result.
- Mistakes: N mistakes costing the viewer something. Each is the mistake, why it hurts, the fix.
- Tools or resources: N things the user actually uses, and what each does for them.
- Lessons: N things the user wishes they knew earlier.
- Signs: N signs you are, or need, something.

RULES
- 3 to 5 items for under 60 seconds. If the user has more, keep the strongest and say which were cut.
- Every item is on the same topic and phrased the same way, so the list is easy to follow.
- A strong first item earns trust. Keep one of the best for last and tease it early ("the last one is the one nobody does"), but only if it is true.
- The number in the hook must match the list.
- Items must come from the user. Never add an item to reach a round number.

LENGTH
20 to 60 seconds.

COMMON MISTAKES
Too many items. Items that overlap. Long explanations that break the rhythm. A number hook with no reason to care.
