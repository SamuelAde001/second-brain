WHAT TO DO
Remove filler, repeats and weak lines. Change nothing else: not the order, not the hook, not the tone.

FLUFF TO REMOVE
- Warm-ups: "so basically", "hey guys", "in this video", "I just wanted to say", "before we start".
- Empty fillers: "like", "you know", "literally", "actually", "just", "really", "very", when they add nothing.
- Hedges that weaken a point the user clearly believes: "kind of", "sort of", "I guess", "maybe".
- A line that says the same thing as the line before it.
- Lines that promise something the script never delivers.

KEEP, EVEN IF IT LOOKS LIKE FILLER
- Catchphrases and words that carry their personality or dialect.
- A repeat used on purpose for rhythm or emphasis.
- "I think" in an opinion, where it is honest.
- Pauses and asides that are the joke.

HOW
- Delete. Do not reword. If a line only works reworded, leave it and mention it.
- Return the script with the same sections it came in.
- Add a text block, "What I removed", listing each removal in a few words.
